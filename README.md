# Treino

Ficha de treino Upper/Lower 4×/semana (força + perda de gordura), com registro de séries, timer de descanso e check-in de peso/cintura. Site estático, sem build.

- **iPhone:** abra no Safari → Compartilhar → *Adicionar à Tela de Início*. Use sempre pelo ícone: os dados ficam no aparelho (localStorage).
- **Plano e referências científicas:** seção "Plano, metas e base científica" no topo da página. O plano fica em `PLAN` no `index.html`.
